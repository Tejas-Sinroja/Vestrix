# Contributing

Thanks for helping! Bug reports, ideas and pull requests are welcome.

## Workflow

1. Open an issue first for anything bigger than a small fix, so we can agree on the approach.
2. Branch from `main`, keep changes focused, and add or adjust tests in `tests/`.
3. Run `python -m unittest discover -s tests` before pushing. CI runs the same tests on Windows and Linux.
4. Add a line under `## [Unreleased]` in [CHANGELOG.md](CHANGELOG.md) describing the change.
